# A Playwright end-to-end suite for the storefront (smoke without secrets, a real Stripe sandbox purchase)

Agent: Claude Code (implementation sub-agent, Sonnet 5.5) · Branch: t3/7468058a (worktree, not pushed) · Task: none (asked by the lead session)

## Goal
An e2e suite in the layout EmDash and `cloudflare/templates` use: root `playwright.config.ts`, `e2e/`, CI; a smoke part that needs
no secrets, a purchase part against a Stripe sandbox, a clean reproducible server, docs, and every assertion group proven by a
mutation.

## Steps
1. Read AGENTS.md, the storefront AGENTS.md, getting-started, CONTRIBUTING, the memory index and EmDash's and the templates'
   Playwright config. Verified the `data-testid` hooks by rendering the pages.
2. `@playwright/test`, `@axe-core/playwright`, `typescript`, `@types/node` as root devDependencies; `playwright.config.ts`; `e2e/`
   with an Nx project (`typecheck`); env overrides `EMDASH_DATABASE_FILE` / `EMDASH_UPLOADS_DIR` in `astro.config.mjs`.
3. Global setup: port check, wipe `.e2e/`, Stripe plan (key, CLI, `stripe listen --print-secret`), server, seed, restart, warm-up.
   Found along the way: Astro 7 backgrounds `astro dev` in an agent shell (`ASTRO_DEV_BACKGROUND=1`), and Stripe CLI 1.55 needs
   `--all-snapshot` for `stripe listen --forward-to`.
4. Probed every page with a scratch Playwright script before writing assertions. Found and fixed three real bugs (below).
5. Smoke specs (home, shop, product, cart, redirects, orders, content, a11y), purchase specs (purchase, purchase-cart).
6. `.github/workflows/e2e.yml` (actionlint clean), `docs/testing.md`, the CONTRIBUTING section, an ADR, four memory files.
7. 25 mutations, one at a time, each restored (table in the final report of the run).
